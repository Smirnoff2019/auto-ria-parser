Інструкція з використання auto-ria-parser (PHP)

1) Що робить програма
Цей парсер:
1. Витягує список марок/моделей для AutoRIA через API.
2. Знаходить оголошення у заданому часовому вікні (за замовчуванням: “за останню добу”).
3. Фільтрує оголошення правилами (рік, коробка передач, колір, паливо, пробіг тощо).
4. Експортує знайдені записи в Excel-файл (.xlsx) із гіперпосиланням.
5. Далі намагається завантажити файл у Google Sheets/Drive через Apps Script (якщо сценарій налаштований).

2) Потрібні вимоги
- PHP версії 8.2+
- Composer (щоб встановити залежності)
- Підтримка PDO SQLite (для `storage/database.sqlite`)
- cURL (для HTTP-запитів через Guzzle та для завантаження через Apps Script)

3) Налаштування перед запуском

Крок 1. Встановіть залежності Composer
У корені проєкту виконайте:
- `composer install`

Якщо `vendor/` уже існує (він у цьому проєкті є) — це може бути не потрібно, але на іншому ПК краще виконати `composer install`.

Крок 2. Вкажіть API ключ AutoRIA
Відкрийте файл `config/app.php` і замініть значення `api_key` на ваш.
Важливо: `generate_brands.php` і сам парсер використовують цей ключ.

Крок 3. Згенеруйте файл `brands_with_id.php`
Парсер `index.php` використовує `brands_with_id.php` (він потрібен, щоб у правилах були ID брендів/моделей).
Якщо `brands_with_id.php` у вас вже є і він актуальний — можна пропустити цей крок.
Запуск:
- `php generate_brands.php`
Під час виконання програма звернеться до API RIA, проставить ID і перезапише/створить `brands_with_id.php` у корені проєкту.

4) Як запустити парсер

Варіант A (через run.bat)
1. Перевірте/відредагуйте `run.bat`.
   У файлі зараз вказано шлях `cd C:\auto-ria-parser`, який може не відповідати вашому розташуванню.
   Замініть на реальний шлях до папки проєкту (наприклад, `C:\Users\Kapitoshka\Desktop\auto-ria-parser`).
2. Запустіть `run.bat` подвійним кліком або з PowerShell.

Варіант B (вручну з PowerShell)
1. Відкрийте PowerShell у папці проєкту.
2. Виконайте:
- `php index.php`

5) Що буде під час виконання
- Парсер встановлює часовий пояс `Europe/Kiev`.
- Визначає інтервал:
  - `from`: “-1 day”
  - `to`: “now”
- Далі проходить по всіх брендах і моделях з `brands_with_id.php`.
- Для кожної моделі робить пагінацію сторінок пошуку (page/countpage).
- Для кожного ID оголошення:
  - отримує детальну інформацію (`info`)
  - застосовує фільтр (`FilterEngine`)
  - додає рядок в масив результатів, якщо оголошення пройшло фільтр.

6) Результат: де лежить Excel
Після завершення парсер створює файл у:
`storage/exports/`

Формат імені файлу:
`Оголошення YYYY-MM-DD - YYYY-MM-DD.xlsx`

Вміст Excel:
Заголовки колонок:
`ID, Дата, Марка, Модель, Рік, Ціна, Телефон, Посилання, Місто, Пробіг, Паливо, Трансмісія, Тип приводу, Колір, VIN`

`Посилання` в таблиці зроблено як гіперпосилання (клітинка H).

7) Логи
Логи записуються в:
`storage/logs/`
Файл має назву виду `parser-YYYY-MM-DD.log`.

8) Як налаштувати фільтри (які авто проходять)
Правила зберігаються у:
`config/brands.php`
Там для кожного бренду вказуються:
- `models` (перелік моделей та їх правила)
- загальні правила бренду (наприклад `transmission`, `exclude_colors`, `max_mileage` тощо)

Після зміни правил:
1. Перезапустіть `php generate_brands.php` (якщо ви змінювали структуру моделей і/або потрібні ID)
2. Потім запустіть парсер `php index.php`.

9) Як змінити часовий діапазон
Інтервал `from/to` задається в `index.php`:
- `$from = new DateTime('-1 day', $tz);`
- `$to   = new DateTime('now', $tz);`

Змініть ці рядки під вашу задачу і запустіть `php index.php` знову.

10) Важлива примітка про “не повторювати” оголошення
У `src/Storage.php` реалізовано SQLite-базу для `processed(auto_id)`.
Але в `src/Parser.php` рядок збереження на даний момент закоментований:
`//$this->storage->save($id);`

Через це в поточній версії парсер може повторно обробляти одні й ті самі оголошення між запусками.
Якщо вам потрібно “пропускати вже оброблені”, зніміть коментар з `$this->storage->save($id);` у `src/Parser.php`.

11) Google Drive/Sheets завантаження (Apps Script)
Експортер робить спробу завантажити файл через Apps Script викликом:
`uploadViaAppsScript($filename);`

Якщо Apps Script не налаштований або ви не хочете завантаження:
1. Відкрийте `src/Exporter.php`
2. Закоментуйте/вимкніть виклик `uploadViaAppsScript($filename);`
3. Запускайте парсер — Excel все одно буде створено локально.

12) Типові проблеми
- Якщо `generate_brands.php` пише “API error”:
  - перевірте `config/app.php` (`api_key`)
- Якщо багато помилок/відмов через ліміти:
  - `AutoRiaClient` має retry і спеціальну обробку `429` (чекає ~60 секунд), але виконання може тривати довше
- Якщо Excel не створюється:
  - перевірте, що існує `storage/exports/` і є права на запис
